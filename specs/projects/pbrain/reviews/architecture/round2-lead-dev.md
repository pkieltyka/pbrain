## Blocking

1. **LD2-B1 · §§8.7, 17, stale content identity.** A file's path, length and CRC-32C can match an earlier version that has different embedding text. An obsolete vector can pass the cutoff for an unrelated query and give range coordinates that no longer fit. Scanning the new body before printing it solves neither the false hit nor the invalid span. Require a SHA-256 bound to the same scan snapshot used for rendering. Hash the whole item or the exact stable projection that supplies title, headings and body to the embedder. Collect it for index build and hybrid search, with the lexical-only path left as the measured reference. Validate start/end against that snapshot before slicing. Cover an injected equal weak version for two different texts. This agrees with the other reviewer.
2. **LD2-B2 · §8.7, verified model bytes and offline shape.** Query preflight checks filenames and sizes, while `Registry.Open` promises verified artifacts. A same-size replacement can load vectors from a different model under the original fingerprint and produce misleading above-cutoff hits. Verify the bytes consumed by the model, either on query open or through an index-time verified artifact with an identity-bound record that prompts revalidation on change. Include this cost in the cold and warm budgets. Also define how one configured `model_path` supplies the whole offline model for a release with several files. A pinned package with explicit verified constituent files is one way to preserve the single-path interface. Test same-size tampering, companion files and a valid offline build. This agrees with the other reviewer.

## Should fix

3. **LD2-S1 · §§8.5 and 8.7, bound the evidence to what was scored.** Honor `SemanticHit.End` and limit the snippet to `[Start, min(End, Start+200))`. Otherwise a short closest passage can quote the next section or a title-only hit can show an unrelated body excerpt. In addition, cap the title/heading prefix given to the model. Long adopted titles and deeply nested headings must leave room for document text before the adapter's token limit, since a model that only saw the prefix did not score the body it is cited for. Version the preparation alongside the chunker. Test adjacent sections, title-only items and an oversized prefix with a short, distinct body passage.
4. **LD2-S2 · §§8.5, 8.7 and 13, start work through an explicit owner.** `Score(ctx, text, eligible)` gets the query and candidates after the lexical scan. It cannot itself start embedding while that scan is running. In the component, give CLI a preflight or source constructor receiving query and view before scan, then keep `Score` responsible for joining that task and comparing against eligible items. Propagate cancellation on a scan or CLI error and close a successfully opened embedder exactly once. This preserves the fixed scoring interface and makes the claimed overlap measurable. Reword §13 so semantic-resource failures degrade to lexical output while the merged mode can still report its own larger minimum.
5. **LD2-S3 · §§8.7 and 14, calibrate against the rendered page.** “No task can lose one” does not follow from unchanged lexical rows: adding continuation fields can reduce the number that fit. Measure first-page usefulness at the same budget in both modes and track regressions. For release abstention, inspect the whole held-out response, not only the added hits, so an irrelevant lexical hit cannot pass as an empty answer. Define the threshold rounding with the inclusive `>=` comparison, especially an exact tie at the quantized cutoff. If no threshold achieves both gates, keep the model out. This partly overlaps the other reviewer.
6. **LD2-S4 · §8.7, interruption checkpoint bound.** The builder checkpoints at item boundaries, so “at most 256 passages or 20 seconds” is not true for a long item. A large personal document has no per-user cache fallback and can leave a large item to redo. State the real bound as the checkpoint budget plus the in-flight item, or checkpoint resumable item work separately without making incomplete entries visible to search. Add a kill/restart fixture on a document larger than the threshold.
7. **LD2-S5 · §9, minimum is a real output state.** Do not require the synthetic zero-row continuation to fit for a nonempty page. With one short tag row, the actual one-row page is smaller than `0 tags. 1 more: --offset 0.` and must succeed at its own exact minimum. Measure zero rows only when the requested page is empty, otherwise measure the first mandatory row and its actual footer. `render.md` already applies that interpretation and tests both the short page and scenario 33's merged minimum.
