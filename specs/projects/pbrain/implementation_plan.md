# Implementation Plan: pbrain

An ordered checklist. The detail is in [architecture.md](architecture.md) (section 18 is the build order this follows) and in the design named with each phase under [components/](components/). ## What can be released when

In the spec's delivery order (section 16), each after phase 28 for what it ships: reads and writes after 14; imports after 15; public fetch after 16; `--bm25` alone after 18; `--semantic` with bge-small after 25; `embeddinggemma-2` after 27; `embeddinggemma-2-q8-0` after 30. A release that lists a model has `--bm25` only if the combined gate passed for every model it lists. The gates judge rendered pages, so they are run again when what a result prints changes.
