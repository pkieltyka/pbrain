# Keep bge-small working after aikit is retired (#62)

Copy the CPU path used by pbrain’s verified `bge-small-en-v1.5` row into `internal/embed/bge/bert`. Base the copy and its oracle on aikit **v1.79.1**, commit `0bbc048828e3e546fcf280659d9d9f4ef694936d`. The current pbrain baseline is `0f3396c` with goinfer v0.6.6. Goinfer no longer depends on aikit and offers no public BERT/WordPiece API. Copying entire upstream packages would also retain other model loaders and execution paths that the audit would then have to maintain.

## 1. Capture the oracle while aikit is still linked

Use the real five-file row through `embed.Verify` and the existing bge adapter on the baseline. Require `PBRAIN_TEST_BGE_MODEL` to point to the verified files; a skipped model test does not qualify the change. Freeze the 59 document inputs in [the #22 fixture order](../../tools/phase28/evidence/gemma-pax-22/fixture-paths.txt), applying `semantic.Passages` to those items in path/ordinal order. Include the existing 22 reference texts in their declared roles, plus explicit empty, whitespace-only, composed/decomposed accents, CJK, punctuation, literal special tokens, unknown/overlong WordPiece words and inputs just below/at/above the 510-content-token cut with a long title prefix and body. Cover both query and document preparation.

Check in the input texts/roles, the expected raw WordPiece IDs for each encoded segment, final CLS/SEP-wrapped IDs, and all 384 output coordinates as little-endian float32 bits. Record the baseline revision, model hashes, CPU features, Go version, architecture and settings. The sentence-transformers JSON is a separate cosine gate; its decimal vectors cannot serve as the bit oracle. Compare old and new **on the same architecture and CPU dispatch path**. Capture like-for-like amd64 and arm64 baselines before dropping aikit; an arm64 emulator can prove numerical parity if native hardware is unavailable. Identify the runner and exercised ISA in the evidence. Preserve the golden data after migration so ordinary verification needs no aikit checkout.

## 2. Extract the byte loader, tokenizer and forward

- Keep pbrain’s `bge.Entry`, `open`, `handoff`, `tokenIDs`, worker scheduling and `bertModel` interface. Redirect the two upstream imports in `bge.go` and `bge_test.go` to the local package. Its boundary is `LoadBERTFromFS(fs.FS, string) (*BERT, error)`, `(*BERT).Tokenizer() *Tokenizer`, `Embed([]int32) []float32`, `Close() error`, and the existing `Tokenizer.Encode(string) []int32` and `SpecialID(string) (int32, bool)`. Keep `LoadTokenizerFromFS` for construction and tokenizer tests. Only the five verified buffers supply model data, with one read per path and no disk or mmap fallback. Preserve close/cleanup, dimension and tensor-bound checks, and the existing fail-closed handoff tests.
- Take the `fsFiles` path from `encoder/bert.go`, the byte-backed parser and typed tensor views from `embed/safetensors.go`, and the WordPiece path in `embed/tokenize.go`, including normalization, added tokens, longest-match splitting and its concurrent memo. The pinned safetensors header includes I64 position IDs alongside F32 weights; allow that valid header without loading unused tensors. Preserve learned positions, type embeddings, CLS pooling, the last-layer row-zero optimization and the float64 norm accumulation in `embed.L2Normalize`.
- Start at `BERT.forward`, `attentionCore`, layer normalization, scratch and parallel dispatch. Place the required FP32 linalg code in `bert/internal/linalg`; follow `MatmulBT`, `MatmulBTInto`, `GELUContractInto` and `SoftmaxRowScaledContractInto` through their actual declarations, helpers, build tags, Go assembly and scalar tails. Keep reduction order, tile boundaries and CPU-feature dispatch on amd64 and arm64. Preserve existing generic fallbacks. Drop model families, BPE/Unigram, GGUF, quantized inference, path loading, mmap, GPU and unused public APIs. Decode the pinned format and explicitly reject unsupported input; do not silently reinterpret it.
- Bring the relevant upstream tests and small fixtures alongside the extracted code: WordPiece normalization/greedy/UNK and concurrent memo tests, FS loader read-once/missing-file/shape checks, CLS row-zero equivalence, and equivalence/tail tests for the retained kernels. Use a small generated F32 BERT fixture for offline CI. Keep the original aikit `LICENSE` and `NOTICE` verbatim under `bert/`, preserve source headers, and add `UPSTREAM.md` mapping the retained files to their upstream paths, tag and commit. Include those license/notice files in both GoReleaser archive definitions and verify presence in all six archives. Do not bundle downloaded weights.

## 3. Prove compatibility and remove the module

1. Match every expected ID and every `math.Float32bits` value on the frozen corpus, with both singleton and multiworker calls. Also run `TestBgeParity`, `TestBgeWorkersSameBytes`, the loader error tests and the worker race tests. A mismatch blocks the migration.
2. Keep the existing model fingerprint `6bd9989750090942b9ff6d86f27ea8a39e255457d0c01659991f87280e181b9b` and index fingerprint `46000384c2fd339d6352b50398ba3a83a7e84cda36e7d53da029f19f92a3363e`. The former hashes row name, ordered file names/digests, dimension 384 and preparation `bge-1`; the latter adds chunker version 1. Neither hashes the library version. Keep runtime label `aikit` as provenance for this port. With an old indexed fixture and warmed shared cache, candidate search must return the same ranked IDs and normal sync must embed zero unchanged passages, preserve the published generation and reuse valid same-row cache entries. Include the personal section.
3. Remove aikit and tidy. Fail CI on any aikit module or replacement targeting it in `go list -m -json all`, any remaining aikit record in `go.mod` or `go.sum`, or an aikit package in a release graph. In `internal/embed/bge/audit_test.go`, scan the main module’s `internal/embed/bge/bert` subtree explicitly: the current main-module skip would silently lose audit coverage. Require the local encoder and kernel packages in every release graph, count selected files by target, record the actual counts and add a regression fixture for the local subtree. Keep all existing runtime checks and exceptions. Build the six archive targets with their release tags and `CGO_ENABLED=0` and run Linux CI.
4. On a quiet CPU, load the model once per arm outside the timer and embed the same 59 documents with four pinned physical cores, `GOMAXPROCS=4`, identical Go flags and workers. Warm once and alternate at least three matched baseline/candidate pairs; report passages/s, median and spread. A sustained slowdown blocks handoff. Investigate a median drop above 3% with another matched run; report smaller repeatable losses too. No GPU or full-corpus sync is needed.
5. Update the bge adapter, dependency/audit and provenance paragraphs in `specs/projects/pbrain/components/semantic.md` and architecture §§8.7/15, plus the implementation checklist. Preserve historical measurements with their original pins. On passing the gates add to `docs/release-notes/next.md`: “bge-small now ships its BERT encoder and WordPiece tokenizer inside pbrain. Its vectors are bit-identical, so existing indexes and cached vectors remain usable.”
