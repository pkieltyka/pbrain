# pbrain v0.4.6

This release adds Metal indexing on Apple Silicon and moves goinfer to v0.6.8. On an Apple M4, `embeddinggemma-2-q8-0` now syncs on the GPU. After upgrading from v0.4.5, only the CUDA fp16 indexes for the Google pack and Q8_0 need a rebuild.

## Install

The standard Linux amd64 archive includes CUDA (NVIDIA) and Vulkan (discrete AMD), and the Linux arm64 archive includes CUDA alone. Both link the fast fp16 CUDA kernels. The `darwin_arm64` archive is now the Metal build. The untagged CPU-only Darwin arm64 build moved to `darwin_arm64_cpu`. The archives ending in `_cpu.tar.gz` contain an untagged CPU-only build, like a plain `go install`. All builds are cgo-free.

To build the GPU binary yourself on Linux amd64, use
`go install -tags cuda,vulkan,eg2_combined,eg2_fp16 github.com/pkieltyka/pbrain/cmd/pbrain@v0.4.6`. On Linux arm64, use `-tags cuda,eg2_combined,eg2_fp16`. On Darwin arm64, use `CGO_ENABLED=0 go install -tags metal github.com/pkieltyka/pbrain/cmd/pbrain@v0.4.6`.

## Upgrading

Run `pbrain sync` after upgrading from v0.4.5 if you use the Google pack or Q8_0 on the CUDA fp16 path, adding `--personal` if you use a personal section. Those fingerprints include the pinned goinfer revision. The rebuild reuses the downloaded model files. Other indexes stay valid.

## Changes

- The Darwin arm64 archive includes Metal indexing for `embeddinggemma-2-q8-0`. Use `pbrain sync --device metal`, `--device metal:0` or auto selection. On the Apple M4, the default combined profile indexed the 219-passage fixture in 23.76 seconds (9.22 passages/s), compared with 27.07 seconds (8.09 passages/s) for stock Metal. Search still uses the CPU. Sync rebuilds a section when its writer profile changes. Use the `darwin_arm64_cpu` archive for the untagged build. [Measurements](https://github.com/pkieltyka/pbrain/blob/v0.4.6/internal/cli/README.measure.md#apple-silicon-metal-q8-indexing-69)
- Aligned the goinfer root, CUDA, Vulkan and Metal modules at v0.6.8. Google and Q8_0 CUDA fp16 fingerprints include the pinned goinfer revision, so indexes built under v0.6.7 need one sync to rebuild. Base indexes retain their fingerprints. On the RTX PRO 6000, all 2,224 compared passages matched bit for bit and the sampled device peaks were unchanged.

per cell in reversed pairs. Rates and wall times are medians. CUDA and
Vulkan device memory figures are sampled peaks. Metal shares system memory.

same-file CPU cosine 0.999. [Trace splits and vector checks](https://github.com/pkieltyka/pbrain/blob/v0.4.6/internal/cli/README.measure.md#matched-device-comparison)
