# pbrain v0.4.2

This release fixes the known issue from v0.4.1 and updates goinfer to v0.6.5. Only Gemma indexes built with the CUDA fp16 fast path need a rebuild. Indexes built with bge-small, or with Gemma on CPU, CUDA fp32 or Vulkan, stay valid.

## Install

The archive layout is the same as in v0.4.1. The standard Linux amd64 archive includes CUDA (NVIDIA) and Vulkan (discrete AMD). The Linux arm64 archive includes CUDA only. Both link the fast fp16 CUDA kernels. The archives ending in `_cpu.tar.gz` contain an untagged CPU-only build, like a plain `go install`. The macOS archives are CPU-only, untested and not supported for now.

To build the GPU binary yourself on Linux amd64, run
`go install -tags cuda,vulkan,eg2_combined,eg2_fp16 github.com/pkieltyka/pbrain/cmd/pbrain@v0.4.2`. On Linux arm64, use `-tags cuda,eg2_combined,eg2_fp16`.

## Upgrading

If you use a Gemma model with the CUDA fp16 fast path (the default on NVIDIA GPUs with compute capability 8.0 or newer), run `pbrain sync` after upgrading. Add `--personal` if you use a personal section. The CUDA fp16 fingerprints include the pinned goinfer revision, so these indexes get a new fingerprint and count as stale until you sync. The rebuild reuses the model files you already downloaded. goinfer compared v0.6.5 with v0.6.4 on CPU and in each of the three CUDA modes, and the vectors matched bit for bit. pbrain ran its own check on the CUDA fp16 path: for both the Google Gemma pack and the Q8_0 GGUF, all 59 passages in its fixture matched v0.4.1 bit for bit.

## Changes

- **goinfer v0.6.5.** The goinfer root, CUDA and Vulkan modules move together to v0.6.5.
- **Decoder startup reads fixed.** The Linux GPU archives no longer read the eight `GOINFER_*` decoder settings before `main`, which fixes the v0.4.1 known issue. The release dependency audit now passes on every release build with no known goinfer startup exceptions. The two platform-runtime exceptions documented in v0.4.1 remain: Go's `GODEBUG` CPU-feature handling and the SQLite driver's C ABI environment snapshot. ([#55](https://github.com/pkieltyka/pbrain/issues/55), [goinfer #70](https://github.com/pkieltyka/goinfer/issues/70))
- **Smaller dependency graph.** goinfer no longer depends on aikit. pbrain still depends on aikit directly for its default bge-small embedder. ([goinfer #71](https://github.com/pkieltyka/goinfer/issues/71))
