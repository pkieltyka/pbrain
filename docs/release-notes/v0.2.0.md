# pbrain v0.2.0

## Upgrade

`pbrain index` was renamed to `pbrain sync`, and the old command name has been removed.
Use `pbrain sync --status` to check index coverage and run `pbrain sync` to rebuild
indexes made by v0.1.1.

## Install

```sh
go install github.com/pkieltyka/pbrain/cmd/pbrain@v0.2.0
```

The default Linux amd64 and arm64 archives include CUDA support. The matching archives
ending in `_cpu.tar.gz` ship an untagged CPU-only binary. `go install` also builds the
CPU-only binary. Linux amd64 runs the CI suite. Linux arm64 is cross-built and vetted.
The macOS archives are CPU-only, untested and unsupported for now.

For CUDA support on Linux with `go install`, use
`go install -tags cuda github.com/pkieltyka/pbrain/cmd/pbrain@v0.2.0`.

## Sync and search

Run `pbrain devices` to list available embedding devices. For EmbeddingGemma 2,
`pbrain sync` uses CUDA on an available NVIDIA device and warns if it falls back
to the CPU. Use `pbrain sync --device cuda` to require CUDA or `--device cpu` to
request the CPU. `PBRAIN_DEVICE` sets the default for sync.

Search always runs on the CPU, including the bounded catch-up for new or changed
notes. `bge-small-en-v1.5` remains the default model. Its sync uses CPU workers and
ignores device selection.

## Sync speed

`pbrain sync` now runs the default model on every core, up to 32. On a Ryzen 9 7950X,
the first index of the 5,000-item, 50 MB test brain took 20 m 25 s on 32 threads, with a peak of about 1.9 GB of memory, and
21 m 1 s on 16 cores. Before this change it took
1 h 18 m on four cores of the same machine. With EmbeddingGemma 2 and the CUDA build on
an RTX PRO 6000, the same index took 1 h 1 m, with about 4.5 GB of host memory and 2.2 GB
on the GPU; it took 1 h 10 m before sync batched passages on the GPU. The GPU batch budget
is 30% of free GPU memory, up to 6 GiB; `PBRAIN_GPU_MEMORY`, in MiB, overrides it.
